# TargetMatte: Language-Grounded Target Guidance for Plug-and-Play Portrait Video Matting
TargetMatte is a plug-and-play framework for language-guided portrait video matting. It enables users to specify target individuals through natural-language descriptions and generates reliable target masks to guide existing video matting models, without modifying their architectures or parameters.

By combining multimodal semantic understanding, portrait-domain adaptation, and matting-oriented refinement, TargetMatte addresses three key challenges: target ambiguity in complex multi-person scenes, incomplete target regions, and inaccurate mask boundaries.

You can see the demo in this project.
