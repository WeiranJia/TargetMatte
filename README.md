# TargetMatte

Video portrait matting aims to estimate high-fidelity alpha mattes while preserving fine-grained structures, such as hair strands, clothing edges, and motion blur. Although recent mask-guided matting methods have achieved promising results, their performance heavily depends on the quality of the provided target masks.

TargetMatte addresses the gap between semantic target understanding and matting-oriented visual guidance. By combining multimodal semantic reasoning, portrait-domain adaptation, and matting-oriented structural refinement, TargetMatte converts natural-language descriptions into reliable spatial priors for downstream video matting.

You can see the triplet samples in the project and the demo on https://weiranjia.github.io/TargetMatte/
